Marker, Backdrop, and Selectors

Learn about CSS markers, backdrops, and selectors.

Study Topics

Pseudo-elements let CSS target special pieces of the browser's UI or an element that aren't normal HTML elements.

pseudo-element

::marker

::marker is the marker box of a list item that represents its bullet/number.

You can change:

  • color
  • white-space
  • unicode-bidi
  • content
  • direction
  • text-combine-upright
  • all font properties (font-size, font-family, font-weight)
  • all animation and transition properties


You can't change:

  • background
  • padding
  • width
  • transform
  • anything else


::marker is best used for quck changes to the color, font, and content.

For full control of the marker (background, transforms, or positioning) hide the native marker with list-style:none and use ::before instead.

::backdrop

::backdrop a special layer (size of viewport) the browser puts behind something in the top layer.

Three things trigger it:

  1. dialog opened with showModal()
  2. an element with the popover atttribute that has been shown
  3. an element placed in fullscreen made via the Fullscreen API


Default semi-transparent black overlay be default

Can be styled with solid colors, gradients, or even backdrop-filter blur that makes the page content behind the dialog appear frosted.

On its own, ::backdrop is an isolated box and does not inherit anything from :root or body. To fix this, redeclare them or use a strategy like setting custom properties on the dialog element and referencing them from there.

::selection

::selection is the portion of text the user has highlighted.

The default style is usually a blue background with white text.

Like ::marker, ::selection can only be styled with these specific things:

  • color
  • background-color
  • text-decoration
  • text-shadow
  • stroke-color
  • stroke-fill
  • -webkit-text-stroke-color


Accessibility and Contrast Matter.

A good rule of thumb is light text on a dark background or dark text on a light background. To know for use, you should use a contrast checker and aim for at least a 4.5:1 contrast ratio.

Overall

::marker

  • List bullets and numbers
  • Limited styling
  • Use ::before for full custom control

::backdrop

  • Layer behind top-layer elements
  • Dialog + Popover + Fullscreen
  • Isolated from normal inheritance

::selection

  • User-highlighted text
  • Limited styling
  • Keep strong color contrast

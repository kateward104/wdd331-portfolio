Form Control Styling

Learn about how to style form controls in CSS beyond the basics.

For a live demo of how these all work, please go to my Contact Page

native styles vs. appearance:none

Native styles - create the default styling for form controls

appearance: none - removes the default styling, allowing you to create a custom look.

You have to create ALL the styles for this, including the focus, active, and hover states.

Best to keep native styles unless doing specific custom styling.

Caution: Windows High Contrast mode and the forced-colors media feature rely on native control rendering to apply system colors correctly. Controls with appearance: none that use custom colors will often lose those colors entirely in forced-colors environments, leaving users with invisible or broken controls.

<select>

This can be difficult to style. You can style the box itself.


Can style:

  • background
  • padding
  • border
  • font



Cannot style:

  • arrow


People get around this by using appearance: none and replacing the arrow with their own svg.

caret-color

The caret is the blinking vertical line that appears when you're typing in a text field.

For example, when you click inside an input and start typing, you see a blinking cursor showing where your next character will appear. That blinking line is called the text caret.

caret-color lets you change the color of the caret. It is often used to match a brand color. Ex: caret-color: var(--accent-color);


This does not change:

  • The color of the text
  • The background of the input
  • The border of the input

:focus-visible

Different controls such as input fields, selects, and range style the focus state differently.

:focus-visible helps to unify them all. Reset the styles, and use :focus-visible to create a consistent focus indicator for all form controls.

Ex:
input,
select,
textarea {
outline: none;
}

input:focus-visible,
select:focus-visible,
textarea:focus-visible {
>outline: 2px solid var(--color-accent);
outline-offset: 2px;
}

Using :focus-visible instead of :focus ensures the ring only appears for keyboard navigation, not mouse clicks.

Range Track and Thumb Styling

Use accent-color for simple customization. Use custom track and thumb styling when you need more control, but expect additional CSS and browser-specific adjustments.

accent-color: Changes the color of the slider's thumb and filled track in supporting browsers.

Custom styling: Use pseudo-elements when you want more control over the track's height, thumb's size and shape, or individual colors.

Track: The line the thumb moves along.

Thumb: The handle you drag to select a value.

Browser differences: Chrome and Safari use ::-webkit- selectors. Firefox uses ::-moz- selectors.

appearance: none: Removes the browser's default styling so you can create your own.

Thumb positioning: Chrome and Safari need a negative top margin to vertically center the thumb over the track. Firefox handles this automatically.


Important Limitations:

  • There is no consistent CSS-only way to independently color the filled and unfilled portions of the track across all browsers.
  • Firefox supports ::-moz-range-progress to style the filled portion.
  • Chrome and Safari do not have an equivalent.
  • For consistent filled-track styling across browsers, JavaScript can update a CSS custom property based on the slider's current value.

field-sizing

field-sizing: content allows the textbox to grow based on how much is typed, without using a scroll bar.

Use min-height and max-height to control the size restraints of the text box. This ensures it doesn't shrink too much, and also puts a cap on the text when needed.

Takeaway Properties

  • accent-color - Establish your brand color for controls
  • field-sizing - Make the textarea grow with content
  • caret-color - Customize the typing cursor (usually color of cursor, but not the text itself)
  • appearance: none - Remove the native select arrow
  • background-image - Add your custom SVG arrow
  • :focus-visible - Establish consistent focus indicators
  • ::-webkit-slider-thumb / ::-moz-range-thumb - Customize the slider handle
  • ::-webkit-slider-runnable-track / ::-moz-range-track - Customize the slider line
